## About me

I build games and production software with a main focus on **Unity/C#**, while also shipping real web products and business systems.

My recent work includes **Life Quest**, a bilingual gamified goal-tracking product with quests, XP, weekly competition, OAuth, PostgreSQL/RLS, Playwright E2E coverage and CI; **ATOM**, a live multilingual commercial website used by an operating advertising business; and production web apps built with **TypeScript, Next.js, Supabase/PostgreSQL and Vercel**.

My background combines hands-on development, manual QA, technical troubleshooting and nearly two years of commercial IT support and technical project coordination. I am comfortable moving between requirements, implementation, debugging, testing and release validation.

Games are where I want to build my career. I care about how gameplay systems, environments, sound and small interactive details shape what the player feels.

**Life Quest** is a bilingual gamified goal tracker that turns real-life goals into quests, concrete actions, XP, levels, weekly bosses, repeatable chains, personal rewards and an optional weekly League.

- **Engineering:** Next.js 16 · React 19 · TypeScript · Supabase Auth · PostgreSQL · RLS · Vercel
- **QA:** Playwright E2E · mobile smoke coverage · regression checks · production dependency audit · GitHub Actions CI
- **Product:** Google OAuth · Demo Mode · lifetime XP · weekly League · permanent podium badges · shareable trophy cards · RU/EN
- **Security:** server-controlled League scoring, protected account deletion, owner-scoped RLS, isolated demo data
